# GNR1007 Learning Game Series

ชุดเกมบทเรียนอินเทอร์แอคทีฟ 10 เกม สำหรับวิชา **GNR1007 การโปรแกรมคอมพิวเตอร์สำหรับวิศวกร**
คณะวิศวกรรมศาสตร์ มหาวิทยาลัยรามคำแหง — เล่นได้ทันทีบนเบราว์เซอร์มือถือ ไม่ต้องติดตั้งแอป

**เข้าเล่น:** `https://<ชื่อบัญชี-github>.github.io/<ชื่อ-repo>/` (แทนที่ด้วยลิงก์จริงหลังเปิดใช้งาน GitHub Pages)

---

## ภาพรวม

โปรเจกต์นี้พัฒนาขึ้นเพื่อแก้ปัญหาการประเมินผลแบบท่องจำในวิชาโปรแกรมมิ่งพื้นฐาน โดยออกแบบให้ทุกข้อคำถามต้องอ่านสิ่งเร้าจริง (โค้ด C ที่คอมไพล์ได้จริง ตาราง หรือสถานการณ์) แล้ววิเคราะห์ ไม่ใช่ตอบจากความจำล้วน พร้อมกลไกเกมที่กระตุ้นให้ผู้เรียนอยากเล่นซ้ำจนครบทุกด่าน

## รายชื่อเกมทั้ง 10 เกม

| เกม | ชื่อ | เนื้อหา | บทที่ |
|---|---|---|---|
| 1 | CPU City | Memory Hierarchy · Compiler/Interpreter · Network Classification | 1–2 |
| 2 | Memory Vault | Data Type Sizing · Overflow Mechanics · Casting | 3 |
| 3 | Operator Arena | Operator Precedence · Prefix/Postfix · Modulo | 4 |
| 4 | Logic Labyrinth | if / else if / else · switch-case · break | 5 |
| 5 | Loop Factory | for · while · do-while · infinite loop | 5 |
| 6 | Trace Detective | Trace table · ++x vs x++ · loop+modulo · nested loop | 5 |
| 7 | Circuit Blueprint | สัญลักษณ์ผังงาน (Flowchart) มาตรฐาน | 10 |
| 8 | Pit Crew | พารามิเตอร์ · return · pass by value · local/global | 6 |
| 9 | Lap Timer | ดัชนีอาร์เรย์ · การวนซ้ำ · out of bounds | 7a |
| 10 | Championship Final | ทบทวนรวมทุกบท | 1–7a, 10 |

## คุณสมบัติหลัก

- **CLIMB MODE — แตะอย่างเดียว** ออกแบบสำหรับหน้าจอมือถือ ไม่มีปุ่มเดิน/กระโดด กดด้วยนิ้วโป้งข้างเดียวได้ทั้งเกม
- **คลังข้อสอบ 36 ข้อต่อเกม** (เขตละ 12 ข้อ) ทุกข้อมีสิ่งเร้าที่ต้องอ่านจริง ถ้าลบสิ่งเร้าทิ้งจะตอบไม่ได้
- **ระบบดาว 6 ดวง** — ตอบถูก 1 ข้อ = 1 ดาว คะแนนเต็ม 6 ข้อ ต่อรอบเล่น
- **ส่งออกคะแนนเป็น CSV** สำหรับอาจารย์เก็บผลการเรียนรู้ของนักศึกษา
- **เรดาร์สรุปผลด้วย Chart.js** พร้อมฉบับ SVG สำรองเมื่อโหลด CDN ไม่สำเร็จ
- ทุกโค้ด C ในคำถามผ่านการคอมไพล์รันจริงด้วย gcc เทียบกับเฉลยแล้ว ไม่มีเฉลยผิด

## เทคโนโลยีที่ใช้

HTML/CSS/JavaScript แบบไฟล์เดียวจบ (single-file) ไม่ต้องมีขั้นตอน build ใช้ Chart.js ผ่าน cdnjs และฟอนต์จาก Google Fonts เก็บสถานะผู้เล่นด้วย `sessionStorage`

## โครงสร้างไฟล์

```
index.html                  หน้าแรก / แกลเลอรีรวมเกมทั้งหมด
game1_cpu_city.html         ... game10_championship.html
```

ชื่อไฟล์เป็นภาษาอังกฤษล้วน ไม่มีเลขเวอร์ชันในชื่อไฟล์ (เพื่อให้ URL ที่แจกนักศึกษาไปแล้วคงที่ตลอดเทอม) เลขเวอร์ชันของแต่ละเกมอยู่ใน footer ของไฟล์นั้น ๆ แทน

## วิธีใช้งาน (สำหรับนักศึกษา)

เปิดลิงก์หรือสแกน QR code ด้วยมือถือ กรอกชื่อผู้เล่น เลือกอวาตาร์ แล้วเริ่มเล่นได้ทันที ไม่ต้องติดตั้งหรือสมัครสมาชิก

## วิธีอัปเดตเนื้อหา (สำหรับผู้ดูแล)

แก้ไขไฟล์ต้นทางแล้วอัปโหลดทับชื่อไฟล์เดิมใน repository นี้ได้เลย ระบบ GitHub Pages จะอัปเดตหน้าเว็บภายในไม่กี่นาทีโดยที่ URL และ QR code เดิมยังใช้งานได้ปกติ
